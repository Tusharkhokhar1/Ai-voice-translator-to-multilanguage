# Ai-voice-translator-to-multilanguage
HOW TO RUN THE PROGRAM

1.OPEN THE CODE FILE USING VSCODE INSIDE A FOLDER. 

2.THEN WE HAVE TO CREATE A VIRTUAL ENVIRONENT AND ACTIVATE THE VIRTUAL ENVIRONMENT IN THE VSCODE.
MANUAL WAY
OPEN TERMINAL
WRITE-> pip install virtualenv
NAME YOUR VIRTUAL ENVIRONMENT-> env
CHANGE DIRECTORY TO ENV-> cd env
THEN GO TO SCRIPTS -> cd .\Scripts\
THEN ACTIVATE THE ENVIRONMENT -> .\activate
OR
CLICK ON -> OPEN QICK ACCESS 
THEN CLICK ON -> SHOEW AND RUN COMMAND
THEN SELECT ->  PYTHON: CREATE ENVIRONMENT
THEN SELECT -> VENV
AND SELECT APPROPRIATE PYTHON INTERPRETER

3.NOW INSATLL ALL THE LIBRARIES USED IN CODE eg.pip install numpy, gradio, assemblyai, translate, os, elevenlabs, pathlib, elevenlabs.client, uuid

4.NOW RUN THE CODE AND PASTE THE RECEIVED IP ADDRESS ON TO THE WEB BROWSER

5. ENTER USER NAME  AND PASSWORD -> user123 AND 12345 respectively.
